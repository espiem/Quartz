# Stinking Cloud
![[z_mechanics/Character Building V1.3/Character Building/Spells/zz_asset-files/icons-creatures-slimes-slime-movement-splash-green.webp|150]]

You create a cloud of putrid mist in the area. The cloud functions as _[[Mist]]_ except it sickens creatures that end their turns within the cloud. (The [[z_mechanics/PF2e Mechanics_1.5_09122024/Effects/Conditions/Concealed]] condition is not a poison effect.)

* * *

**Critical Success** The creature is unaffected.

**Success** The creature is [[Sickened 1]].

**Failure** The creature is [[Sickened 1]] and [[z_mechanics/PF2e Mechanics_1.5_09122024/Effects/Conditions/Slowed]] while in the cloud.

**Critical Failure** The creature is [[Sickened 1|Sickened 2]] and [[z_mechanics/PF2e Mechanics_1.5_09122024/Effects/Conditions/Slowed]] until it leaves the cloud.
