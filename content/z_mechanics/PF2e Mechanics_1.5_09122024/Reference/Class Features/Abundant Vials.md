# Abundant Vials
## Feat 17
### [[z_mechanics/PF2e Mechanics_1.5_09122024/PF2e Journals/Classes/Alchemist]]

**Category** classfeature; 




You're permanently [[z_mechanics/PF2e Mechanics_1.5_09122024/Effects/Conditions/Quickened|Quickened]], and can use the extra action only to use [[Actions/Quick Alchemy|Quick Alchemy]] to create a quick vial.
